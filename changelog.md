# 1.1.0

* Player 2 input is now injected through `GJBaseGameLayer::queueButton`, the
  same path the game uses itself, so the jump actually happens.
* The mouse button is now configurable: use the **Bind mouse button** button in
  the settings and press the button you want.
* Added an optional keyboard bind.
* Added debug logs setting.

# 1.0.0

* Initial release.
* Bind Player 2's jump to the left mouse button in two-player mode.
